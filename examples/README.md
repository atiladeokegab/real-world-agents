# Banking & Financial Services — public example cases

The 50 synthetic practice cases for the Banking & Financial Services track, copied unchanged from
[DwellyOrg/HackatonPublicCases](https://github.com/DwellyOrg/HackatonPublicCases/tree/main/Banking%20%26%20Financial%20Services)
(commit `9bcdca5`).

Each case lives in `<NNN>/`:

- `index.md` — the initial request, case details, summary and outcome
- `history.md` — the events in time order
- `attachments/` — supporting files (not every case has them)

These are practice data only. To test a decision, give the system only the events up to a
decision point and hide the later events and the outcome (see the upstream README).
